# WenKey

个人 iOS 输入法：26 键全拼 + 英文键盘，整句联想为核心，离线语音，分类不限量剪贴板，
圆润液态玻璃外观，各部位颜色可自由调整，带交互反馈。

## 功能

已做（P0 骨架）：

- 26 键 QWERTY，拼音模式按键显示大写字母，简体中文输出
- 整行拼音整句联想：打一整行拼音，候选栏直接给整句，不用一个字一个字选
- 英文键盘：Shift 大小写、双击 Shift 大写锁定
- 候选栏分词候选，点单字上屏后剩余音节继续拼
- 圆角液态玻璃按键（iOS 26 glassEffect），触感与按键动画

计划中：

- P1 效率手势：滑行输入（英文）、空格键光标、删词手势、长按符号、双击空格句号
- P2 词库扩展与自学习、英文纠错联想
- P3 离线语音（系统 Speech 离线识别）
- P4 剪贴板分类管理 + 常用语
- P5 主题分部位调色、反馈打磨
- P6 打包安装

明确不做：贴纸 / GIF / 表情包商城、翻译、站内搜索、皮肤商城、会员广告、
AI 聊天改写、游戏新闻、悬浮键盘、手写、账号云同步。个人用的键盘，纯本地更干净。

## 构建

需要 Xcode 26，iOS 26 SDK：

```sh
open WenKey/WenKey.xcodeproj
```

选 `WenKey` target 运行。签名需填自己的 Development Team；
App Group（`group.com.wenx.wenkey`）需在开发者账号开通，
否则主题与开关跨进程同步会回落为单进程默认值。

CI 在 GitHub Actions 上做编译验证（`macos-latest` + Xcode 26，不签名）。

## 启用

装机后：设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → WenKey。

剪贴板历史功能需要手动开启“允许完全访问”，否则键盘扩展读不到系统剪贴板，
这是苹果的限制。
